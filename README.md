## 🎯 نظرة عامة على المشروع
منصة **خدماتي** هي بيئة متكاملة تربط بين **العملاء** الباحثين عن خدمات احترافية و**مقدمي الخدمات** المستقلين والشركات في عموم المحافظات العراقية. تم تصميم المنصة لتوفر تجربة مستخدم عصرية وسلسة تضاهي المنصات العالمية مع تكييف كامل لخصوصية المستخدم العراقي.

---

## 🚀 الميزات والخصائص الشاملة

### 1. منظومة التحقق من الأرقام العراقية
- **التحقق الصارم من صحة الأرقام**: يقبل النظام حصرياً أرقام شبكات الاتصال العراقية المعتمدة (**Zain Iraq**, **Asiacell**, **Korek**).
- **التنسيقات المدعومة**:
  - الصيغة المحلية: `07724978301` أو `07801234567` أو `07501234567` (11 رقماً).
  - الصيغة الدولية: `+9647XXXXXXXXX` أو `009647XXXXXXXXX` أو `9647XXXXXXXXX`.
- **التوحيد التلقائي (Normalization)**: تحويل جميع الأرقام المدخلة تلقائياً في قاعدة البيانات إلى الصيغة المحلية القياسية `07XXXXXXXXX` لتجنب التكرار وتسهيل التواصل.
- **التطبيق الشامل**: مفعل في نماذج تسجيل المستخدمين، تعديل الملف الشخصي، طلبات الخدمات، ونماذج مقدمي الخدمات.

### 2. تأكيد الحسابات عبر الواتساب
- **نظام OTP آمن**: توليد رمز تحقق سري من 6 أرقام صالح لمدة 10 دقائق مشفر ومحفوظ في جلسة آمنة.
- **رابط وتطبيق الواتساب المباشر**: إنشاء رابط `wa.me` بنقرة واحدة يفتح محادثة واتساب جاهزة مع رسالة التوثيق المسبقة.
- **التحقق التفاعلي بدون إعادة تحميل (AJAX)**:
  - طلب إرسال الرمز وتأكيده فورياً.
  - إمكانية إعادة إرسال الرمز مع عداد زمني.
- **شعار التوثيق الأخضر**: إظهار علامة "مؤكد عبر الواتساب" في الملف الشخصي لزيادة موثوقية المستخدمين ومقدمي الخدمات.

### 3. نظام الكابتشا الأمني الذكي (SVG CAPTCHA)
- **مولّد متجهي نقي (Pure Python SVG)**: لا يعتمد على أي مكتبات خارجية ثقيلة (لا يحتاج Pillow أو خطوط نظام خارجية).
- **أمان ومقاومة للروبوتات**:
  - خطوط مشوهة عشوائية ومنحنيات بيزير مموجة (Bezier Wave Distortion).
  - نقاط تشويش لونية متناثرة تمنع القراءة الآلية لبرمجيات OCR.
  - أحرف وأرقام مائلة بزوايا وألوان متغيرة تمنع التخمين.
- **توثيق رقمي مشفر (HMAC Cryptographic Tokens)**: توقيع الرمز ومطابقته برمجياً مع مهلة زمنية (TimestampSigner) لمنع هجمات إعادة الإرسال (Replay Attacks).
- **تصميم تفاعلي مستوحى من Cloudflare / reCAPTCHA**:
  - خيار تفاعلي ذكي "أنا لست برنامج روبوت".
  - زر تحديث فوري مرن يولد رمزاً جديداً عبر AJAX بدون إعادة تحميل الصفحة.
  - تصميم منسق وأنيق يتكيف تلقائياً مع الأجهزة الذكية والوضع الليلي والنهاري.

### 4. الوضع الليلي والنهاري المتكيف (Dark & Light Modes)
- **مظهر عصري فاخر**: تصميم مخصص للألوان الداكنة (Dark Palette) مريح للعين مع تباين عالي للنصوص والعناصر.
- **حفظ التفضيلات**: تخزين الوضع المفضل في متصفح المستخدم (`localStorage`) مع استشعار تلقائي لتفضيلات نظام التشغيل (`prefers-color-scheme`).
- **أزرار عالية التباين**: معالجة كاملة لجميع الأزرار الحمراء (`btn-danger`, `btn-outline-danger`) والقوائم المنسدلة لضمان وضوح النصوص 100% في كلا الوضعين.

### 5. دعم العملة المزدوجة (IQD / USD)
- **تبديل فوري للعملة**: إمكانية استعراض أسعار الخدمات إما بـ **الدينار العراقي (د.ع)** أو **الدولار الأمريكي ($)** بنقرة واحدة من القائمة العلوية.
- **محول عملات مدمج**: فلاتر قوالب مخصصة (`service_price`, `currency_format`) لتحويل دقيق وسلس للأسعار في جميع صفحات الموقع.

### 6. سوق الخدمات والتصنيفات
- **تصنيفات شجرية ذكية**: تصنيفات رئيسية وتخصصات دقيقة تشمل (خدمات المنزل والصيانة، السيارات، التقنية والبرمجة، التصميم والتسويق، التعليم والتدريب، التصوير، كتابة المحتوى، وغيرها).
- **محرك بحث وفلترة متطور**:
  - البحث بالكلمات المفتاحية في العنوان والوصف والوسوم (Tags).
  - الفلترة حسب نطاق السعر، مستوى الخدمة، التصنيف، والخدمات المميزة أو العروض المخفضة.
  - ترتيب حسب (الأحدث، الأعلى تقييماً، الأكثر طلباً، الأقل سعراً).
- **صفحة تفاصيل الخدمة المتكاملة**:
  - استعراض معرض الصور ومقاطع الفيديو التعريفية.
  - باقات الأسعار ومزايا وسلبيات الخدمة.
  - بطاقة مقدم الخدمة مع معدل سرعة الرد ونسبة الإنجاز والتقييمات.

### 7. دورة حياة الطلبات والتتبع التفاعلي
- **طلب الخدمة المباشر**: نموذج سلس لطلب الخدمة مع إضافة متطلبات وتفاصيل خاصة، واختيار وسيلة الاتصال وتطبيق كوبونات الخصم.
- **مخطط التتبع الزمني (Timeline Tracker)**: متابعة حية لمراحل الطلب:
  `جديد / قيد الانتظار ➔ قيد المراجعة ➔ قيد التنفيذ ➔ مكتمل / جاهز للتسليم ➔ تم التسليم`.
- **نظام إلغاء مرن**: إمكانية إلغاء الطلب من قبل العميل قبل بدء التنفيذ مع نافذة تأكيد آمنة وتوضيح سبب الإلغاء.

### 8. المحفظة الرقمية والرصيد
- **محفظة مالية لكل مستخدم**: رصيد حالي، رصيد معلق، وإجمالي الأرباح أو المدفوعات.
- **سجل المعاملات المالية (Ledger)**: تتبع تفصيلي لكل عملية شحن، دفع لطلب، استرداد أموال، أو سحب أرباح.
- **محاكاة الشحن والسحب الفوري**: واجهات لتجربة شحن الرصيد وسحب الأرباح مع التحقق المالي.

### 9. المحادثات والرسائل الداخلية
- **غرف محادثة خاصة بكل طلب**: تواصل مباشر وآمن بين العميل ومقدم الخدمة داخل المنصة.
- **مؤشرات الرسائل غير المقروءة**: تحديث فوري لعدد الرسائل الجديدة في الشريط العلوي.

### 10. لوحات التحكم المتعددة (Multi-role Dashboards)
- **لوحة العميل (Customer Dashboard)**: متابعة الطلبات النشطة، الخدمات المفضلة، الإشعارات، وسجل العمليات.
- **لوحة مقدم الخدمة (Provider Dashboard)**: إحصائيات الأداء، الطلبات الواردة وقبولها أو تحديث حالتها، إدارة الخدمات المنشورة، ومتابعة الأرباح.
- **لوحة إدارة المنصة (Admin Management)**: إدارة التصنيفات، مراجعة مقدمي الخدمات الجدد، التحكم بالعروض وكوبونات الخصم، وإحصائيات عامة للمنصة.

### 11. تطبيق الويب التقدمي (PWA)
- **جاهزية التثبيت (Installable)**: ملف `manifest.json` وأيقونات مخصصة تتيح تثبيت المنصة كتطبيق أصيل على هواتف Android و iOS والحاسوب.
- **العمل دون اتصال (Offline Support)**: بفضل `Service Worker` مدمج وصفحة مخصصة عند انقطاع الإنترنت مع زر فحص الاتصال التلقائي.

## 🏛 البنية الهيكلية للتطبيقات

```
ail_project/
│
├── accounts/          # إدارة المستخدمين، الملف الشخصي، التحقق العراقي، توثيق الواتساب
├── services/          # الخدمات، التصنيفات، الباقات، التقييمات، محرك البحث
├── requests/          # دورة حياة الطلبات، تتبع حالة الطلب، الإشعارات
├── dashboard/         # لوحات التحكم المخصصة (عميل، مقدم خدمة، مشرف)
├── wallet/            # المحفظة المالية، سجل العمليات، الشحن والسحب
├── conversations/     # نظام المحادثات والرسائل الفورية بين المستخدمين
├── favorites/         # قائمة الخدمات المفضلة (Wishlist)
├── analytics/         # تتبع المشاهدات وإحصائيات المنصة
├── core/              # العناصر المركزية: كابتشا SVG، مدقق الهواتف، السمات، PWA
│   ├── captcha.py     # محرك توليد وفحص كود الكابتشا المشفر
│   └── validators.py  # مدقق ومطابق أرقام الهواتف العراقية
├── static/            # الملفات الثابتة (CSS, JS, الصور, Service Worker, Manifest)
└── templates/         # قوالب HTML مبنية بنظام الوراثة ودعم RTL الكامل
```

## 💻 متطلبات التشغيل
- **Python**: الإصدار 3.10 أو أحدث.
- **Django**: الإصدار 5.0+.
- **قاعدة البيانات**: SQLite افتراضياً (أو PostgreSQL لبيئة الإنتاج).
- **المتصفحات المدعومة**: Chrome, Firefox, Safari, Edge بأحدث إصداراتها.

## 🛠 دليل التثبيت والتشغيل السريع

### 1. استنساخ المشروع وإنشاء البيئة الافتراضية
```bash
# إنشاء بيئة العمل
python -m venv venv

# تفعيل البيئة (Windows)
venv\Scripts\activate

# تفعيل البيئة (Linux / Mac)
source venv/bin/activate
```

### 2. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 3. تطبيق ترحيل قاعدة البيانات (Migrations)
```bash
python manage.py migrate
```

### 4. تشغيل خادم التطوير المحلي
```bash
python manage.py runserver 8001
```
الموقع متاح الآن على: `http://127.0.0.1:8001/`

## 🔒 الأمان والحماية
1. **حماية CSRF**: مدمجة في جميع النماذج وطلبات AJAX.
2. **تشفير كلمات المرور**: استخدام خوارزمية `PBKDF2 SHA256`.
3. **أمان الكابتشا**: توليد هاش مشفر ومحدد بوقت زمني غير قابل للتعديل من جانب العميل.
4. **تطهير المدخلات (Sanitization)**: تنقية جميع مدخلات المستخدمين وأرقام الهواتف قبل التخزين بقاعدة البيانات.
5. **إدارة الصلاحيات (Role-Based Access Control)**: حماية مسارات مقدمي الخدمات والمديرين عبر ديكوريتورز مخصصة (`@login_required`, `@provider_required`, `@admin_required`).
